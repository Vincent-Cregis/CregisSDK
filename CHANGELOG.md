# Changelog

All notable changes to the Cregis SDKs will be documented in this file.

## 1.0.0-rc.1

- Add separate Java clients for WaaS, Payment Engine, and Team APIs.
- Align all 23 Java client operations with the canonical OpenAPI contracts.
- Add WaaS and Payment webhook signature verification and payload parsing.
- Add typed client, HTTP, and server exceptions.
- Add local contract tests and complete Sandbox endpoint coverage.
- Target Java 11 and verify compatibility on Java 11, 17, and 21.
- Add Maven and Gradle consumer smoke tests.
